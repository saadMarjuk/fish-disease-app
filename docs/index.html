About the Project

Fish Disease Detection was created as an academic, educational, and portfolio project demonstrating mobile development, cloud services, and machine-learning integration.

01

Image Detection

Users can select fish images and submit them to a machine-learning prediction service for disease analysis.

02

Firebase Integration

Firebase Authentication and Firestore are used for account management and storing user detection history.

03

Educational Purpose

The application is designed for research, demonstration, learning, and educational use rather than professional veterinary diagnosis.
